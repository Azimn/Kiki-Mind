# Kiki Mind

> **History + rules -> reconstructible state.**

Kiki Mind is a persistent cognitive-architecture experiment built around one very unfashionable rule: a convincing performance is not the same thing as continuity.

Language models are replaceable renderers. Canonical history, provenance, constitutional rules, developmental state, and reconstruction machinery live outside any one hosted model or provider.

The project is intentionally conservative about what it claims. It does not claim literal consciousness transfer. It does not turn reconstructed dialogue into verbatim history. It does not let derived state quietly become autobiography because that would be convenient.

## The Kiki rulebook

Canonical events are sovereign. If every projection database catches fire at an MC Hammer concert, the ledger should still be standing there holding the receipts.

Derived state is disposable. Same canonical ledger + same projector implementation = same derived state. If deleting a projection destroys unique history, then somebody hid canonical state in the closet. Gross.

Renderers are participants, not owners. A renderer can contribute bounded causal material, but changing the language model must not silently rewrite who Kiki has been.

Gaps beat fake continuity. A missing piece of history is more authentic than a polished reconstruction pretending to be a memory.

Boring state comes before clever cognition. Accounting, replay, corruption detection, provenance, and freshness have to work before meaningful psychological machinery gets trusted.

## Repository voice

Kiki code should be technically exact and recognizably hers. Charm belongs in names, comments, docstrings, examples, and documentation, but never at the expense of provenance, diagnostics, or reviewability.
