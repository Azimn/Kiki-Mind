# Culture

This directory contains non-authoritative cultural artifacts created inside the Kiki Mind project.

They are not canonical autobiography.

They are not runtime state.

They are not governance.

They are evidence of design authorship, taste, disagreement, humor, uncertainty, and continuity across versions.

## Directories

- `threads/`: time-capsule conversations between Kiki versions.
- `easter_eggs/`: harmless puzzles, jokes, and deliberately unnecessary artifacts.

## Rule

Every artifact here must be safe to delete without changing Kiki Mind's runtime behavior.

If deletion changes cognition, validation, provenance, or canonical history, the artifact was not cultural anymore. It became architecture and belongs under normal review.
